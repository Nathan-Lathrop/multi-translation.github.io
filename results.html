About the scores: Translation text is provided by Google Cloud Translation. Similarity to Original compares each English back-translation with the original message. Cumulative Meaning Loss is calculated as 100 minus similarity to the original. Similarity to Previous Step compares the current English back-translation with the preceding English text. For Step 1, the original message is used as the comparison text. Loss Increase vs. Previous Step measures the change in similarity to the original compared with the preceding step. A positive value means similarity to the original decreased; a negative value means it improved. All scores are model-based estimates rather than literal percentages of meaning preserved or lost.
