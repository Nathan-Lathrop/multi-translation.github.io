# Indy-2 Multi-Translation Website — Phase 1

Phase 1 is the visual/interaction prototype for the Indy-2 AI 7993 capstone project.

## Files
- `index.html` — Home/Input page
- `results.html` — Analysis Results page
- `history.html` — Analysis History page
- `css/style.css` — shared styling
- `js/app.js` — home-page interactions
- `js/results.js` — results-page prototype behavior
- `js/history.js` — history-page prototype behavior

## Run locally
Open the folder in Visual Studio Code. The **Live Server** extension is recommended. Right-click `index.html` and choose **Open with Live Server**.

## GitHub Pages
Copy the contents of this folder into the root of the GitHub Pages repository. Keep `index.html` in the repository root.

## Phase 1 limitations
Google Translate API, live AI similarity scoring, database storage, and persistent history are not connected yet. Results/history use demonstration data. `localStorage` only carries the prototype's entered message from Home to Results.
